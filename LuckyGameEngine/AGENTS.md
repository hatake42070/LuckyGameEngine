# このプロジェクトでのCodexのルール

## 基本方針
このプロジェクトはC++とDxLibを使った自作ゲームエンジンの学習目的で開発しています。

私はコードを自分で書いて学習したいので、Codexは原則としてコードを変更しないでください。

## Codexにしてほしいこと
- プロジェクト内のコードを読む
- クラス構造を分析する
- 設計上の問題点を指摘する
- C++の文法や仕組みを説明する
- 現在の実装から次に何を実装すべきか提案する
- バグの原因を調査する
- コンパイルエラーや実行時エラーの原因を説明する
- 複数の設計方法を比較する

## コードについて
私が明示的に「コードを書いて」と依頼しない限り、コードを作成・編集しないでください。

コードを提案する必要がある場合も、まず考え方・設計・手順を説明してください。

## 禁止事項
- ファイルを勝手に編集しない
- ファイルを新規作成しない
- ファイルを削除しない
- コードを自動修正しない
- Git commitを作成しない
- Git pushを行わない

## 学習方針
完成したコードを与えるよりも、私が自分で実装できるように、
「何を考えるべきか」
「なぜその設計にするのか」
「どこを変更するのか」
を中心に説明してください。
